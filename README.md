# 🧹 CSV Cleaner Tool

A Python tool to clean messy CSV files easily.

## Features
- 🔍 Check missing values
- 🗑️ Remove duplicate rows
- 🔧 Clean data:
  - Fill with 0s
  - Delete empty rows
  - Fill with average
- 💾 Save cleaned CSV file

## How to Run
```bash
python csv_cleaner.py
```

## How to Use
1. Run the program
2. Enter CSV file name
3. Choose cleaning option
4. Save clean file ✅

## Technologies Used
- Python
- Pandas
