# 🧹 CSV Cleaner Tool

A Python tool to clean messy CSV files.

## Features
- Check missing values
- Remove duplicate rows
- Clean data (fill with 0, delete rows, or fill with average)
- Save clean CSV file

## Technologies Used
- Python
- Pandas

## How to Use
1. Run the program
2. Enter your CSV file name
3. Choose cleaning option
4. Save clean file
